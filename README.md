# Problem Sets - Fundamentos de Ciencia de Datos

Repositorio de actividades desarrolladas para el curso de **Fundamentos de Ciencia de Datos**.

## Problem Set 1

### P1 - CRISP-DM vs. enfoques modernos

Se realizó un análisis comparativo entre **CRISP-DM** y los enfoques modernos de Ciencia de Datos, utilizando **Michelangelo de Uber** como caso de estudio. Se abordaron conceptos como **Feature Store, MLOps, monitoreo continuo, data drift, concept drift y exploración iterativa**.

### P2 - Tratamiento de datos ENAHO

Se realizó el procesamiento y transformación de microdatos de la **ENAHO** mediante **Python, Pandas y NumPy**. Las principales actividades fueron:

- Lectura y filtrado de datos del Módulo 1.
- Análisis de la variable `result` y la no respuesta.
- Creación de la variable `target`.
- Extracción de departamento y provincia mediante `ubigeo`.
- Clasificación del área urbana y rural.
- Clasificación de la región natural.
- Comparación de la tasa de no respuesta entre **2024 y 2025**.
- Exportación de bases y reportes procesados.
